\section{A Configuration}
\label{sec:x-config}

A configuration is a trait with associated types for the sockets and
associated constants for the numbers, and a build is one item:
\code{config!} writes the config type and both of its impls.
\code{Default} builds the top, because a register's default is its
reset value and a socket's is its implementation, and \code{main}
reaches the design through nothing but the config. Two builds differ
in a filter length and a clock rate, and the program was run with each
in turn.
