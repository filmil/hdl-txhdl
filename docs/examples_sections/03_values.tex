\section{Values}
\label{sec:x-values}

Two-valued \code{Bit}, nine-valued \code{Logic} in IEEE 1164's order,
and the numeric vectors \code{U<N>} and \code{I<N>} with the width as a
const parameter. Arithmetic is wrapping and explicit, a multiply names
its result width, and a Rust integer converts to a vector where one is
expected, so a literal reads as a literal.
