\section{A Waveform}
\label{sec:x-trace}

Every example so far printed its trace as text. This one writes a
waveform, in VCD, which Surfer and GTKWave open. A signal's name is
the field it lives in: \code{\#[derive(Trace)]} on a unit registers
each field under its own name, a nested unit gives the hierarchy, and
the testbench names what it holds itself when it adds it,
\code{vcd.add("msb", \&msb)}. Nothing is named twice and nothing is
named at construction. \code{\#[derive(Value)]} says how a value of
the design's own appears: a struct as its fields concatenated, an enum
as the index of its variant. Registers, the ends of wires and
channels, and crossings register themselves; plain values in a unit
are constants and register nothing.

Time in the file is in ticks, two per cycle of the default clock: a
clock rises at one tick and falls at the next, and a value a rising
edge drove is written at that tick's end, so a register's change is
seen after the edge that caused it. Figure~\ref{fig:x-trace} is the
file, drawn. The build made it:
\code{vcdcvt} turned the VCD into a signals database,
\code{sqlite2drawtiming} wrote the four chosen signals in drawtiming's
text form, Listing~\ref{lst:x-trace-dt}, and \code{//tools/dt2tikz}
drew that text, so the figure cannot differ from what the example
wrote. The two converters are prebuilt tools pinned by checksum for
every platform they ship for.
