\section{How to Read This}
\label{sec:x-reading}

Every section from Section~\ref{sec:x-values} on is one example: a
paragraph saying what it shows, the file, and, when the file is a
program, what it printed when the build ran it. The files are under
\code{lib/examples} in the project repository, each is a target there,
and the ones that print are run with \code{bazel run
//lib/examples:ex\_\emph{name}}.

The examples use the runtime crate \code{txhdl}, and this document
shows the crate only through its public interface, which the build
extracts from the source and which is the last section,
Section~\ref{sec:x-interface}, for looking things up. What a function
does inside is the runtime document's business~\cite{runtime}; what it
is for and how it is called is here.

The order is the order of the language: values, then a transaction,
then an interface, then a unit with processes, a pipeline, clocks, a
hierarchy, a configuration, then four complete designs, a blinky, a
state machine, an asynchronous FIFO and an arbiter, then a waveform
written from a design, and from there on every example has one: a
join of two events, a pipeline with several invocations in flight, a
structural netlist, both edges of a clock, and one pipeline lowered
twice.
