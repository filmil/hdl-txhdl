\section{A Pipeline}
\label{sec:x-pipeline}

A pipeline is an \code{async fn}. The operators in
\code{txhdl::pipeline} each take a cycle, so the depth of \code{mac}
follows from the two operations it awaits without manual stage placement.
The plain \code{fn} beside it cannot write \code{.await} and cannot
measure cycles, directly enforcing the invariant that a combinational
body remains timeless.
