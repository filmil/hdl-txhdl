\begin{abstract}
One example per concept of TxHDL, from values to an asynchronous FIFO
between two clocks. Each is a file that compiles, and a listing here is
that file, included when the document is built. The examples that run
are run by the build as well, and their output follows the listing, so
the trace under the FIFO is the trace the FIFO produced. The runtime
the examples are written against is shown only through its public
interface, extracted from the source by the build; its implementation
is the runtime document's business.
\end{abstract}

\begin{IEEEkeywords}
Hardware description languages, embedded domain-specific languages, Rust,
examples.
\end{IEEEkeywords}
