\section{What Was Counted}

Every file tracked by git in the repository \code{HDL/txhdl}, outside
\code{third\_party/}, was counted with \code{wc -l}, so comments and
blank lines count as lines. Lock files (\code{Cargo.lock},
\code{MODULE.bazel.lock}, \code{cargo-bazel-lock.json}, and
\code{multitool.lock.json}) and \code{.bazelversion} were excluded:
because they are generated artifacts, including them would add thirty
thousand lines of external configuration. \code{third\_party/} holds
vendored \LaTeX{} packages and the IEEE document class, under their own
licenses, and is not this project's work.

The measurement was taken on September 13, 2026, at commit
\code{0ab36f3} of the mainline, the commit before this document and
its script were added. Listing~\ref{lst:stats-script} displays the
script; executed from the root of a checkout, it reports
Tables~\ref{tab:stats-topic} and~\ref{tab:stats-lang} for that
checkout. The topics are the directories of the tree, named in the
script. The script has gained topics since that date, covering the
parts library, Vreteno software, and newly created directories
(issue 745), so a run today sorts into rows the tables below do not
have.

\section{What the Numbers Say}

The core language footprint is compact. The runtime and macro together
total approximately 6,300 lines of Rust. Within the runtime,
\code{comp.rs} and \code{netlist.rs} comprise three quarters of the
volume, with the remainder distributed across type definitions,
foreign unit declarations, pipeline primitives, and helper functions.

The Vreteno processor is roughly half the size of the language runtime.
The CPU core comprises 815 lines, the instruction decoder 522 lines, and
the reference model 364 lines. On-chip bus peripherals (including the
UART, timer, crossbar router, and data memory) total 560 lines.

Technical prose approaches parity with codebase implementation.
Documentation, architectural design notes, and formal specifications
account for approximately 13,800 lines, compared to 15,000 lines of
Rust. Because documents incorporate code listings by reference rather
than duplicating text, these counts reflect pure explanatory prose.

Examples remain modular and focused: thirty-two files averaging ninety
lines each, with each file demonstrating an isolated architectural concept.

Tooling represents one quarter of the Rust codebase. The two testbench
generators, \code{vshim} and \code{fst2tb}, form the largest utilities
at roughly 550 lines each, demonstrating that verification harnesses
require substantial engineering investment.
