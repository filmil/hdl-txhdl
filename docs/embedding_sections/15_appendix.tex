\section{The Runtime}
\label{app:runtime}

The types and modules this paper has introduced, consolidated into one
crate, \code{txhdl}, at \code{//lib}. Every file below is included
verbatim from the tree at build time, so the listing and the library
cannot differ. Nothing here has been lowered to hardware: it is the
prototype the lowering experiment of Section~\ref{sec:e-next} would be
written against.
